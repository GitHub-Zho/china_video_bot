# Background music (BGM)

Drop royalty-free music files here (`.mp3` / `.m4a` / `.wav` / `.aac` / `.flac` / `.ogg`).

- The pipeline picks **one track per video** (deterministic per video id) and mixes it
  under the voiceover at 30% volume with automatic ducking (music dips when the voice speaks).
- **Empty folder = no BGM** — the pipeline runs fine without music, loudness
  normalization still applies.
- 3–6 tracks with different moods (upbeat / calm / cinematic) is plenty.

## Where to get free commercial-use tracks

- Pixabay Music — https://pixabay.com/music/  (no attribution required)
- YouTube Audio Library — https://www.youtube.com/audiolibrary (check per-track license)
- Mixkit — https://mixkit.co/free-stock-music/

Suggested vibe for China travel/food content: light acoustic, lo-fi beats,
or cinematic ambient. Avoid tracks with vocals (they fight the narration).
